# AgriAssist Database

This folder contains the SQL scripts used to create and configure the MySQL database for the AgriAssist agriculture assistance application.

## Database Technology

- MySQL

## Project Files

- `database.sql` — Contains the SQL commands used to create and configure the database tables.

## Setup Instructions

1. Install and start MySQL Server.
2. Open MySQL Workbench or the MySQL Command Line Client.
3. Open or execute `database.sql` to create the required database tables.
4. Configure the database connection settings for the backend.
5. Start the AgriAssist backend.

**Note:** Make sure the database and required tables are created before running the backend.

## Related Components

- `backend/` — Flask API and machine learning functionality.
- `frontend/` — User interface built with HTML, CSS, and JavaScript.
