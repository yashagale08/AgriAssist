# AgriAssist Datasets

This folder contains the datasets used in the AgriAssist agriculture assistance project for crop recommendation, crop production analysis, soil analysis, and water usage analysis.

## Dataset Files

| File | Description |
|---|---|
| `Crop_recommendation.csv` | Dataset used for crop recommendation model development. |
| `crop_production_data.csv` | Contains crop production data for agricultural analysis. |
| `soil_analysis_data.csv` | Contains soil-related data for agricultural analysis. |
| `water_usage_data.csv` | Contains water usage data for agricultural analysis. |

## Purpose

These datasets support agricultural data analysis and machine learning tasks within AgriAssist.

## Usage

1. Download or clone the AgriAssist repository.
2. Open the CSV files using Python, Pandas, Excel, or another compatible tool.
3. Use the datasets with the relevant analysis or machine learning code.

## Notes

- Keep the original column names and data structure when using the datasets.
- Check the dataset contents and source information before using them for further research.
- Dataset availability does not guarantee that every file is currently used by the running application.
