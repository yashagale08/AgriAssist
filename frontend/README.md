# AgriAssist Frontend

The frontend of **AgriAssist**, an agriculture assistance application built using HTML, CSS, and JavaScript.

## Features

- **Home:** Main dashboard for accessing project features.
- **Crop Recommendation:** Get crop recommendations based on input conditions.
- **Crop Price Prediction:** Predict crop prices using the backend.
- **AgriAssist Chatbot:** Interact with an AI-powered agriculture chatbot.
- **Prediction History:** View previous predictions.
- **Settings:** Access application settings.
- **Language Support:** English, Hindi, and Marathi.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API for communication with the backend

## Project Files

- `index.html` — Website structure and pages.
- `style.css` — Website styling and layout.
- `script.js` — Frontend functionality and backend API requests.

## How to Run

1. Download or clone the AgriAssist repository.
2. Open the `frontend` folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension.
4. Ensure the AgriAssist backend is running and the API address in the JavaScript configuration matches your backend address.

## Backend Integration

The frontend communicates with the Flask backend through HTTP API requests to retrieve crop recommendations, crop price predictions, and chatbot responses.
